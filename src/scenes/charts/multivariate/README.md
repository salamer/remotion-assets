```text
┌────────────────────────────────────────────────────────────┐
│  PARALLEL COORDINATES                                      │
│  100┤    │      │      │      │                            │
│     │  ●─┼──────●──────┼──●───┼─●  Us                      │
│   50┤    │   ●──┼──────●──────●                            │
│     │    │      │      │      │     Peer                   │
│    0┤────┴──────┴──────┴──────┴──                          │
│      Price  Growth Margin  NPS  Scale                      │
└────────────────────────────────────────────────────────────┘
```
