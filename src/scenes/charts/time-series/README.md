# Charts · Time-series

随时间变化。看线框选图。

```ts
import { LineChart, DualAxisChart, CandlestickChart } from "./scenes";
```

## LineChart

单系列折线 + 点值标注。

```text
┌────────────────────────────────────────────────────────────┐
│  REVENUE                                                   │
│                                                            │
│                                    · 11.1                  │
│                               ·───●                        │
│                          ·───● 9.9                         │
│                     ·───●                                  │
│                ·───●                                       │
│           ·───●                                            │
│  ─────●───                                                 │
│  20  21  22  23  24  25                                    │
└────────────────────────────────────────────────────────────┘
```
