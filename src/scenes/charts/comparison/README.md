# Charts · Comparison

两点 / 两期直接对照。

```ts
import { DumbbellChart, SlopeChart, SmallMultiples } from "./scenes";
```

---

## DumbbellChart

每行：起点 ○───● 终点。

```text
┌────────────────────────────────────────────────────────────┐
│  DUMBBELL                          from ○───● to           │
│                                                            │
│  US      ○──────────────●                      42 → 58     │
│  EU      ○────────●                            31 → 40     │
│  APAC    ○──────────────────●                  22 → 51     │
│  LATAM   ○────●                                18 → 25     │
└────────────────────────────────────────────────────────────┘
```

## SlopeChart

```text
┌────────────────────────────────────────────────────────────┐
│  SLOPE                         2020            2025        │
│                                 │               │          │
│  Us ────────────────────────────●───────────────●          │
│                                 │  ╲            │          │
│  Peer ──────────────────────────●───╲───────────●          │
│                                 │    ╲          │          │
│  Laggard ───────────────────────●─────╲─────────●          │
│                                 │               │          │

```
