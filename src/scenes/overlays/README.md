# Overlays

透明叠加在真人 / B-roll 上。默认不要包 `Frame`。

```ts
import { TickerOverlay, PresenterOrbitOverlay } from "./scenes";
```

---

## TickerOverlay

左下角行情条。

```text
┌────────────────────────────────────────────────────────────┐
│  (transparent / B-roll)                                    │
│                                                            │
│                                                            │
│                                                            │
│                                                            │
│                                                            │
│  ┌────────┬────────┬────────┬────────┐                     │
│  │ AIRBNB │ ABNB   │ +4.6%  │ $92B   │                     │
│  └────────┴────────┴────────┴────────┘                     │
└────────────────────────────────────────────────────────────┘
```

---

## PresenterOrbitOverlay

画面四周环绕卡片（中间留给真人）。

```text
┌────────────────────────────────────────────────────────────┐
│  ┌──────┐                              ┌──────┐            │
│  │ 1    │                              │ 2    │            │
│  │RATES │      (presenter / camera)   │DEMAND │            │
│  └──────┘                              └──────┘            │
│                                                            │
│  ┌──────┐                              ┌──────┐            │
│  │ 3    │                              │ 4    │            │
│  │SUPPLY│                              │REGUL.│            │
│  └──────┘                              └──────┘            │
└────────────────────────────────────────────────────────────┘
```
