# Metrics

1～6 个 headline 数字。看线框选组件。

```ts
import {
  HeroMetric,
  SplitMetric,
  ShareMetric,
  MetricGrid,
  FactGrid,
} from "./scenes";
```

## FactGrid

2×2 事实框（标签 / 大数 / 注释）。

```text
┌────────────────────────────────────────────────────────────┐
│  FACTS                                                     │
│  Market at a glance                                        │
│                                                            │
│  ┌──────────────────────┐  ┌──────────────────────┐        │
│  │ MARKET SIZE          │  │ 5Y CAGR              │        │
│  │ $480B                │  │ 8.4%                 │        │
│  │ 2025 estimate        │  │ 2020–2025            │        │
│  └──────────────────────┘  └──────────────────────┘        │
│  ┌──────────────────────┐  ┌──────────────────────┐        │
│  │ TOP 3 SHARE          │  │ LEADER               │        │
│  │ 63%                  │  │ Company A            │        │
│  │ Highly concentrated  │  │ Largest by revenue   │        │
│  └──────────────────────┘  └──────────────────────┘        │
└────────────────────────────────────────────────────────────┘
```
