# Frameworks

Consulting / decision frames under `src/scenes/frameworks/`.

| Subfolder | Use for |
|---|---|
| `strategy/` | Qualitative matrices (strategy, risk, prioritization, opportunity) |
| `planning/` | Issue trees, metric drivers, scenarios, roadmaps, bridges |
| `process/` | Swimlanes (who / what / when) |

**Distinctions**

- `IssueTree` — qualitative decomposition of a question
- `MetricDriverTree` — quantitative KPI tree with operators
- `StrategyMatrix` / `OpportunityMatrix` — qualitative; not `ScatterPlot`
- `SwimlaneDiagram` — process ownership; money flows stay in `diagrams/flow`
